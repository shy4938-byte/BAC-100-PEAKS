# BAC 100 PEAKS PC v0.9.0

압축을 풀고 BAC-100-PEAKS-PC-v0.9.0.html을 브라우저에서 여세요. 이전 버전 파일 대신 이 파일을 사용하세요.

100개 산마다 다른 창작 일러스트가 산 이름 오른쪽에 기본으로 표시됩니다. 누르면 크게 볼 수 있습니다. 실제 정상석 사진이나 정확한 지형 실루엣을 재현한 자료가 아닙니다. 일러스트는 파일에 내장되어 인터넷 없이도 표시됩니다. 실제 앱 화면은 preview-seorak.png / preview-halla.png를 보세요.

정상석 사진 등록·변경·삭제 기능은 제거했습니다. 이전 개인 사진 저장소를 읽거나 삭제하지 않으며 외부로 업로드하지 않습니다. 별도 사진 선택이 필요 없습니다.

코스 안내는 v0.8.0의 공식 자료 대조를 유지합니다. 공식 추천 32개 산 / 참고 추천 68개 산이며 전체 검증 완료가 아닙니다. 근거·미완료 항목은 동봉된 자료를 참고하세요. 외부 출처·네이버 링크에는 인터넷이 필요합니다. 관리 환경 정책으로 실제 Windows file:// 더블클릭 실행은 미검증이며, 같은 HTML을 로컬 문서로 열어 오프라인 기능과 외부 요청이 없음을 검증했습니다.
