# BAC 100 PEAKS PC 0.6.0

ZIP 압축을 풀고 BAC-100-PEAKS-PC.html을 Chrome 또는 Edge로 여세요.
설치·회원가입이 필요하지 않습니다.

- 명산100 공개 목록 기반 100개 마커, 확대/큰 지도/산 이름 표시/검색
- 산별 식당 후보 3개: 이름, 메뉴, 주소, 기준점부터의 직선거리
- 가게별 네이버 평점·리뷰 검색 링크와 정보 출처

네이버 숫자 별점은 직접 확인하지 못해 표시하지 않습니다.
추천은 공개 자료에서 거리순으로 고른 후보이며, 현재 영업 여부는 확인 전입니다.
거리 기준은 코스 접근 지점 또는 산 정상, 반경 최대30km입니다. 실제 도로 이동 거리와 다릅니다.

명산 목록의 최신 공식 대조는 BAC 사이트 503으로 미완료입니다.
상세 코스는 기존 공식 확인 15개이며 나머지는 확인 중입니다.
지도 출처: 통계청 KOSTAT 2013 / southkorea/southkorea-maps.
맛집 사실 정보 출처: khh180cm/baekbangihaeng-map 및 각 가게의 원출처 링크.
원자료의 사진·리뷰 본문·다른 서비스 평점은 사용하지 않았습니다.

단위16개, 웹 브라우저7개, PC 단일 문서 기능 검사 통과.
실제 Windows file:// 및 네이버 사이트 응답 검사는 미완료입니다.
