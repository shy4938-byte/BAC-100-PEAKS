# BAC 100 PEAKS 갤럭시 v0.9.0

[설치 파일 다운로드](https://github.com/shy4938-byte/BAC-100-PEAKS/raw/refs/heads/galaxy-download-v0.9.0/BAC-100-PEAKS-Galaxy-v0.9.0.apk)

갤럭시에서 APK를 받고 다운로드 알림 또는 내 파일 → 다운로드에서 엽니다. 휴대폰이 요청하면 파일을 연 앱의 ‘이 출처 허용’을 선택하고 설치합니다. BAC 100 PEAKS 아이콘을 열면 사용할 수 있습니다. 계정·웹 서버 없이 사용합니다. APK를 다른 갤럭시 사용자에게 공유할 수도 있습니다.

100개 산별 일러스트와 코스·지도는 내장되어 오프라인 표시됩니다. 정상석 사진 등록 기능은 없습니다. 네이버·공식 자료 링크에는 인터넷이 필요합니다. 공식 추천 32개 산 / 참고 추천 68개 산으로 전체 공식 검증 완료가 아닙니다.

APK 빌드·서명 검증과 패키지 내부 화면의 모바일/오프라인 검사를 완료했습니다. 실제 삼성 기기 설치·Android WebView 실행은 미검증입니다. preview-mobile.png는 APK 내부 파일을 모바일 Chromium에서 연 검증 화면이며 삼성 실기기 캡처가 아닙니다. 설치 조건·업데이트·검증 범위는 ANDROID.md, 코스 자료 범위는 COURSE-PAIRS.md를 참고하세요.
